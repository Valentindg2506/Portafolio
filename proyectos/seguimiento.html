Descripción General

Seguimiento CAS es una aplicación web progresiva (PWA) desarrollada para la agencia inmobiliaria CAS Real State. Permite gestionar el ciclo completo de captación de prospectos: desde el primer contacto hasta el cierre de la operación, con seguimiento detallado de cada interacción, pipeline visual y métricas en tiempo real.

El sistema está diseñado para funcionar en dispositivos móviles como una app nativa, permitiendo a los agentes gestionar sus prospectos desde cualquier lugar con soporte offline y sincronización automática.

Arquitectura y Módulos

⚡ Captación de Prospectos

Registro y gestión del pipeline de captación con estados personalizables y seguimiento por etapas.

⚡ Seguimiento de Interacciones

Historial completo de contactos por tipo: llamadas, emails, visitas, WhatsApp con timestamps.

⚡ Dashboard con KPIs

Panel de métricas en tiempo real con indicadores clave de rendimiento de captación.

⚡ Sistema de Inquilinos

Módulo de gestión de inquilinos con contratos, pagos y seguimiento de incidencias.

⚡ API RESTful

Backend con endpoints JSON para todas las operaciones CRUD con autenticación por token.

⚡ Service Worker

Funcionamiento offline con cache de recursos estáticos y sincronización al recuperar conexión.

Flujo de Funcionamiento

  1. Registro de prospecto: El agente registra un nuevo contacto con datos de la propiedad y del propietario.
  2. Seguimiento activo: Se registran todas las interacciones (llamadas, visitas, mensajes) con fecha y notas.
  3. Pipeline visual: Los prospectos avanzan por las etapas del embudo de captación.
  4. Cierre y métricas: Dashboard con estadísticas de conversión y rendimiento por agente.
